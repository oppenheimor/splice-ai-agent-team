## Agent 平台 Web Search 工具调研
- 调研了 7 个平台的搜索实现：Hermes、Workbuddy、Tavily、智谱AI、MetaSearchMCP、Claude API、Browser-use
- 核心发现：
  - Hermes 支持 8 个搜索后端，搜索和提取可拆分，3 子代理并行
  - Workbuddy 一次任务可并行 20 次工具调用（多维度关键词搜索 + 网页获取）
  - Tavily 专为 AI Agent 设计，4 种搜索深度，额外提供 /research 和 /map 端点
  - 智谱AI Search Agent 采用 msearch（多查询并行）+ mclick（选择性深度阅读）两阶段检索
  - MetaSearchMCP 聚合 30+ 搜索提供者，统一 Schema 归一化 + URL 去重
  - Claude API 提供 web_search + web_fetch 互补工具，支持动态过滤
- 推荐 MVP 方案：Tavily 单后端，让 LLM 自主生成多维度查询词

## Chat 阶段系统 Prompt 设计
- 参考 fbs-iplib Agent Team 的库长执行规范，设计了完整的 Chat 系统 Prompt
- Prompt 11 个模块：身份定位、诊断上下文感知、三层运行模式、首响契约、场景路由、证据等级、输出纪律、工具规范、降级策略、合规护栏、诊断结果联动
- 三层运行模式：L1 速答(60s) / L2 结构化分析(3-5min) / L3 深度调研(10-15min)
- 首响契约（冷启动）：认出用户 → 本轮先做 → 本轮不做 → 下一步
- 9 种场景路由：3 人群(TE/EP/AP) × 3 级别(L1-2/L3-4/L5)
- 证据等级：A(一手数据) / B(行业分析) / C(AI推断) / D(未验证)
- 降级策略：搜索超时→空结果→完全不可用→渲染失败 四级降级
- 产出文件：lib/agent-team/agents/prompts/requirements-diagnosis.ts
- 同时更新了 prompts/index.ts（注册新 builder）、types.ts（新增 PromptBuilderName + ExternalToolName + AgentManifest.externalTools）
- 更新了架构文档第 10 节状态和新增第 12 节
