# Splice AI Agent Team

Splice AI Agent Team 是一个基于 Next.js、Prisma 和 PostgreSQL 的 AI Agent 团队应用。

## 快速开始

首次拉取项目后，执行统一初始化命令：

```bash
pnpm dev:init
```

该命令会处理本地 `.env`、依赖安装、PostgreSQL 容器启动、Prisma Client 生成和数据库迁移。

启动开发服务：

```bash
pnpm dev
```

访问：

```text
http://localhost:3000
```
