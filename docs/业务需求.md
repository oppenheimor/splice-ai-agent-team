# 业务需求

## Overview

我想构建一个自己的 Agent Team 平台. 每一个 Agent 都是：

* 独立设计、可访问的前端页面（可能随着 Agent 功能的不同有不同的页面风格）；

* 具备对话能力

* 拥有**差异化交互逻辑与 UI**（不仅仅是提示词不同）


平台支持持续扩展新的 Agent，每个 Agent 可根据业务目标自定义交互流程与界面形态。但是基本的能力要实现复用（比如聊天对话能力、AGUI 等等）


## 已规划的 Agent 示例：

| Agent 名称 | 功能说明 | 访问路径 |
|-----------|----------|----------|
| 需求诊断 Agent | 通过多轮问卷式对话收集用户信息，完成需求分析与诊断 | `/agent-team/requirements-diagnosis` |
| 寻宝游戏 Agent | 根据用户目标（如求婚、生日惊喜等），通过追问与分析，输出完整执行方案（计划、时间线、物品清单等） | `/agent-team/treasure/hunt` |

更多 Agent 正在规划中...
