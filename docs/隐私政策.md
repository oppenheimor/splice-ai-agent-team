## 2. 我们如何收集和使用个人信息

我们会遵循合法、正当、必要、诚信原则，在实现具体功能所必要的范围内处理你的个人信息。

### 2.1 注册、登录与账号识别

当你注册、登录或保持登录状态时，我们可能收集和使用：

- 手机号、用户名、密码哈希值或其他登录凭证；
- session 标识、登录 cookie、登录时间、退出时间、登录状态；
- IP 地址、浏览器 User-Agent、请求来源、基础日志信息。

用途：

- 创建和识别账号；
- 保持登录状态；
- 保护账号和服务安全；
- 排查登录异常、接口异常和滥用行为。

说明：我们不会明文保存你的密码。密码应当以哈希方式保存。

### 2.2 AI Agent 对话与内容生成

当你使用 AI Agent、发送消息、填写问卷、生成方案或报告时，我们可能处理：

- 你主动输入的文本、选项、需求、目标、预算、偏好、计划、业务背景等内容；
- AI 生成的回复、报告、清单、计划、诊断结果；
- 会话 ID、Agent 类型、消息时间、模型调用状态、错误信息；
- 为完成服务所需的上下文、提示词、工具调用结果和生成参数。

用途：

- 向你提供 AI 对话、分析、诊断、方案生成和报告生成服务；
- 维持多轮对话上下文；
- 排查生成失败、内容异常和服务故障；
- 优化 Agent 的交互体验、扣费规则和服务质量。

特别提醒：请不要在对话中输入与当前任务无关的身份证件号码、精确住址、银行卡号、健康信息、行踪轨迹、未成年人信息、他人隐私、商业秘密或其他敏感信息。若你主动输入上述信息，我们会在提供服务所必要范围内处理。

### 2.3 本地缓存与浏览器存储

为了改善网页体验，本服务可能使用浏览器 localStorage、sessionStorage 或类似本地存储能力保存：

- 当前或历史会话草稿；
- 问卷答题进度；
- 诊断结果临时缓存；
- 会话列表、页面折叠状态、前端 visitorId 或偏好设置。

用途：

- 防止刷新页面导致答题或会话丢失；
- 帮助你恢复历史对话；
- 保持页面交互偏好。

说明：localStorage 中的数据保存在你的浏览器本地。你可以通过浏览器设置清除，但清除后可能无法恢复本地会话和草稿。

### 2.4 积分、订单与交易记录

当你查看积分、消耗积分、未来进行充值或使用付费功能时，我们可能处理：

- 用户 ID、积分余额、积分流水、扣费原因、任务类型；
- 订单号、支付状态、支付金额、支付渠道、支付完成时间；
- 任务预估消耗、实际消耗、失败退回记录。

用途：

- 展示积分余额和流水；
- 完成付费、扣费、退款、补偿和账务核对；
- 防止重复扣费、恶意退款、异常交易和规则绕过；
- 处理客服、争议和合规留存。

说明：如果后续接入微信支付、支付宝、Stripe 或其他支付服务，我们会在本政策或页面中补充具体第三方服务信息。

### 2.5 安全、风控与服务分析

为了保障服务安全、定位问题和改进体验，我们可能处理：

- IP 地址、请求路径、请求时间、HTTP 状态码、错误日志；
- 设备和浏览器基础信息；
- 页面点击、按钮、会话 ID、visitorId、Agent 类型、事件时间等产品分析事件；
- 异常登录、接口频率、失败次数、滥用行为记录。

用途：

- 保障账号、接口、模型调用、积分和服务安全；
- 防止攻击、刷接口、绕过计费、垃圾注册和滥用；
- 统计功能使用情况、排查页面问题、优化产品体验。

## 6. 个人信息保存期限

我们仅在实现处理目的所必要的最短时间内保存你的个人信息，除非法律法规要求或允许更长保存期限。

一般保存规则如下：

| 信息类型 | 保存期限或确定方法 |
| --- | --- |
| 账号信息 | 账号存续期间保存；账号注销后在合理期限内删除或匿名化，法律法规另有要求除外 |
| session 与登录记录 | 按安全、审计和排障需要保存合理期限 |
| AI 会话和报告 | 为提供历史记录、排障、客服和服务改进保存；如当前仅保存在 localStorage，则主要由你的浏览器本地保存 |
| 积分、订单和账务记录 | 按交易、税务、审计、争议处理和法律要求保存 |
| 日志和安全记录 | 按安全防护、排障和合规需要保存合理期限 |
| 本地缓存 | 保存在你的浏览器本地，直到你清除缓存或产品主动清理 |

如果保存期限届满，或处理目的已经实现、无法实现、你撤回同意、账号注销且无继续保存的合法理由，我们会删除或匿名化处理相关个人信息。

## 7. 我们如何保护个人信息

我们会采取与服务规模、数据类型和风险程度相匹配的安全措施，包括但不限于：

- 使用 session cookie 识别登录状态，避免在 cookie 中保存完整用户信息；
- 对密码进行哈希保存，不保存明文密码；
- 对数据库、服务端接口和后台权限进行访问控制；
- 记录必要日志以发现异常调用、攻击、刷接口和滥用行为；
- 对敏感配置、数据库连接、模型 API Key 等进行环境变量管理；
- 在发现安全事件后，根据法律法规要求采取补救措施并进行必要告知。

尽管我们会尽力保护你的个人信息，但互联网服务无法保证绝对安全。请你妥善保管账号、密码、验证码和登录设备，不要在不可信环境中使用本服务。

## 9. 未成年人个人信息

本服务主要面向成年人。我们原则上不主动面向不满 14 周岁的未成年人提供服务，也不主动收集其个人信息。

如果你未满 18 周岁，应在父母或其他监护人的同意和指导下使用本服务。如果监护人发现未成年人未经同意使用本服务或提交个人信息，可以通过本政策列明的联系方式联系我们，我们会依法处理。

如果本服务未来明确面向不满 14 周岁的未成年人，或不可避免处理不满 14 周岁未成年人的个人信息，我们会制定专门的个人信息处理规则，并依法取得监护人同意。
