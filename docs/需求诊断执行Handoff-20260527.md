## 已实现内容

### 页面流程

- `/requirements-diagnosis`
  - 专业商务风 Hero 首页
  - 最近评测预览
  - 历史入口
- `/requirements-diagnosis/quiz`
  - 12 题逐题答题
  - Q10/Q11 多选
  - localStorage 防刷新丢失
  - Q3/Q8/Q10/Q12 过渡提示
  - 答完后前端算法生成本地报告并跳转结果页
- `/requirements-diagnosis/result`
  - 结构化报告骨架即时渲染
  - 调用后端保存 DB
  - SSE 流式叙事增强
  - 失败降级和重试
  - 报告结构已补齐：思辨坐标、英文简称/诠释、雷达图、五大维度、数据到行动、AI 实践画像、推荐路径、三步建议、最后想说的话、转化引导、不止一种可能
- `/requirements-diagnosis/chat/[id]`
  - 专业商务风 Chat Shell
  - 自动注入诊断上下文
  - 支持继续同一评测对应的 Chat 会话
- `/requirements-diagnosis/history`
  - 当前用户全部历史评测
  - 展示 Chat 状态和消息数
  - 支持查看结果 / 继续深度诊断

### API

- `POST /api/agent-team/diagnosis/complete`
  - 保存 `DiagnosisQuizResult`
  - 返回 `text/event-stream`
  - SSE 格式：`data: {...}\n\n`
  - 支持 `{ quizResultId, retryNarrative: true }` 仅重试叙事
- `GET /api/agent-team/diagnosis/history`
  - 返回当前用户全部历史记录，按时间倒序
- `POST /api/agent-team/chat`
  - `requirements-diagnosis` 必须携带 `quizResultId`
  - 从 DB 读取诊断结果
  - 创建/更新 `DiagnosisChatSession`
  - 注入 system prompt
  - 记录 `DiagnosisChatMessage`
